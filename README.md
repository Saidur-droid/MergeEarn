## Getting Started

### Prerequisites

- Node.js 18+
- Nimiq wallet
- Git

### Installation

```bash
git clone https://github.com/Saidur-droid/MergeEarn.git
cd MergeEarn
npm install
```

### Running Locally

```bash
npm run dev
```

## Contribution

We welcome contributions! Check out our [contribute page](https://github.com/Saidur-droid/MergeEarn/contribute) or browse the live bounty board above for available tasks.

A task is paid only when MergeEarn shows it as `FUNDED`. Nimiq is authoritative for funding/payout and GitHub is authoritative for the work.
